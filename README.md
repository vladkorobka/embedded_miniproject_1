# Miniproject 1 — Кольорова лампа (ESP32-S3)

Вбудований RGB-світлодіод, колір якого перемикається двома кнопками, а яскравість автоматично підлаштовується під освітлення в кімнаті за допомогою фоторезистора (LDR).

## Демо

https://github.com/user-attachments/assets/b4d73d50-5a42-481c-8ead-3e2da841a946

## Що вміє

- 4 кольори: `red`, `green`, `blue`, `yellow`
- Права кнопка — наступний колір, ліва — попередній (по колу)
- Програмний антидребезг кнопок (30 мс)
- Яскравість за показами LDR: чим темніше в кімнаті, тим яскравіше світить лампа
- 19 дискретних рівнів яскравості (0…180), щоб світло не «мерехтіло» від шуму АЦП
- Лог у Serial кожні 500 мс: поточний колір, сире значення АЦП і яскравість

## Обладнання

| Компонент       | Підключення                                       |
| --------------- | ------------------------------------------------- |
| Плата           | ESP32-S3-N16R8 (16 MB flash)                      |
| RGB LED         | вбудований, пін `RGB_BUILTIN` (WS2812)            |
| Кнопка «вліво»  | GPIO 38 → GND (внутрішній pull-up)                |
| Кнопка «вправо» | GPIO 39 → GND (внутрішній pull-up)                |
| Фоторезистор    | GPIO 4 (ADC), дільник напруги з резистором на GND |

Кнопки активні по низькому рівню: використовується `INPUT_PULLUP`, тож зовнішні резистори не потрібні.

## Збірка та прошивка

Проєкт на [PlatformIO](https://platformio.org/).

```bash
pio run                # зібрати
pio run -t upload      # прошити
pio device monitor     # монітор порту, 115200 бод
```

## Налаштування

Основні константи у [src/main.cpp](src/main.cpp):

| Константа     | Значення  | Опис                                   |
| ------------- | --------- | -------------------------------------- |
| `DEBOUNCE_MS` | 30        | час антидребезгу кнопок, мс            |
| `RAW_LIGHT`   | 250       | сире значення АЦП при яскравому світлі |
| `RAW_DARK`    | 5000      | сире значення АЦП у темряві            |
| `LEVELS[]`    | 0…180     | таблиця рівнів яскравості              |
| `COLORS[]`    | 4 кольори | назва + RGB-складові                   |

`RAW_LIGHT` і `RAW_DARK` варто підібрати під конкретний фоторезистор: подивіться `ADC raw` у моніторі порту при яскравому світлі та при закритому долонею датчику.

## Як це працює

1. `debounceStep()` фільтрує дребезг: стан кнопки приймається лише тоді, коли сире значення не змінювалося довше за `DEBOUNCE_MS`.
2. Перехід `0 → 1` (натискання, а не утримання) змінює `colorIndex`.
3. `analogRead()` з LDR через `map()` + `constrain()` переводиться в індекс таблиці `LEVELS`, звідки береться яскравість.
4. `updateLed()` масштабує RGB-складові поточного кольору на яскравість і викликає `neopixelWrite()` — лише коли щось справді змінилося.
